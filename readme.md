# ODDAWURL — Next-Gen Luxury Gadgets

A modern luxury-gadget e-commerce frontend built with React, TypeScript, Vite, Tailwind CSS, and Three.js. ODDAWURL explores an immersive storefront experience through product discovery, reusable UI components, and interactive shopping interfaces.

## 🔗 Project Links

- **Live Demo:** https://e-commerce-web-murex-two.vercel.app/
- **GitHub Repository:** https://github.com/itskamalhere/E-commerce-web

## ✨ Features

The project includes frontend components for:

- **Product Discovery** — Product grids, category sections, and new-arrival content.
- **Shopping Cart UI** — Cart drawer and quantity-management interface.
- **Wishlist UI** — A dedicated wishlist drawer and cart/wishlist context.
- **Product Quick View** — A modal-based product preview interface.
- **Interactive Product Experiences** — Three.js-based 3D exploration components.
- **Checkout Interface** — A checkout modal UI for the shopping flow.
- **Brand Storytelling** — Dedicated brand-story and product-benefit sections.
- **Reusable Components** — Modular components for headers, footers, notifications, and other storefront sections.

*Note: Component availability does not guarantee that every interaction is fully functional. Real payments, backend order processing, and persistent customer accounts are not claimed as implemented.*

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/itskamalhere/E-commerce-web.git
   ```

2. Navigate to the project directory:

   ```bash
   cd E-commerce-web
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Runs TypeScript checks and builds the production app |
| `npm run preview` | Previews the production build locally |
